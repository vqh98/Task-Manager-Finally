# ربات تلگرامی مدیریت تسک و جلسه

این ربات همه تعاملات روزمره را داخل تلگرام انجام می‌دهد: ثبت جلسه از پیام فورواردشده، مدیریت تسک با ماتریس آیزنهاور، درصد پیشرفت و آخرین توضیح، یادآوری ددلاین و داشبورد مدیریتی.

## امکانات

- استخراج عنوان، تاریخ و ساعت جلسه از پیام معمولی یا فورواردشده و تأیید قبل از ثبت
- ذخیره مستقل رویدادها در دیتابیس داخلی ربات
- انتخاب طول جلسه هنگام ثبت و تعیین طول پیش‌فرض شخصی از بخش تنظیمات
- پیام خودکار برنامه جلسات فردا هر شب ساعت ۲۲
- ثبت تسک، ددلاین، مسئول پیگیری، اولویت آیزنهاور، درصد پیشرفت و آخرین توضیح
- یادآوری یک‌باره وقتی دو روز یا کمتر تا ددلاین مانده باشد
- لیست تسک‌ها مرتب‌شده بر اساس اولویت و نزدیک‌ترین ددلاین
- داشبورد آماری کاملاً درون تلگرام
- فرمان مدیریتی با زبان طبیعی و API، با فیلتر امن روی داده‌های همان مدیر
- محدودسازی دسترسی به شناسه‌های تلگرام مجاز
- امکان افزودن و حذف مدیر توسط مالک، کاملاً داخل تلگرام
- فضای کاری مستقل برای هر مدیر؛ هیچ مدیری تسک‌ها و جلسات مدیر دیگر را نمی‌بیند
- استفاده رایگان از ربات با کد ورود یک‌بارمصرف یا چندبارمصرف ساخته‌شده توسط مالک
- انتخاب نوع مصرف، ثبت آمار ورود و غیرفعال‌کردن کد از پنل مالک
- فضای کاری مستقل برای هر کاربری که با کد ورود وارد می‌شود
- کنترل خودکار تاریخ انقضای دسترسی کاربران

## راه‌اندازی

1. با `@BotFather` در تلگرام یک ربات بسازید و توکن بگیرید.
2. Python 3.11 یا جدیدتر نصب کنید.
3. محیط مجازی بسازید و وابستگی‌ها را نصب کنید:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

4. فایل `.env.example` را با نام `.env` کپی و مقادیر `BOT_TOKEN` و `ALLOWED_USER_IDS` را تکمیل کنید. برای فهمیدن شناسه تلگرام خود می‌توانید از `@userinfobot` استفاده کنید.

شناسه‌های `ALLOWED_USER_IDS` نقش مالک دارند. پس از اجرای ربات، مالک از دکمه **مدیریت دسترسی** می‌تواند مدیر جدید اضافه یا دسترسی او را لغو کند. مدیر جدید کافی است ربات را Start کند تا شناسه عددی‌اش را ببیند و آن را برای مالک بفرستد. داده‌های هر مدیر با شناسه تلگرام او جدا می‌شود.

## ورود کاربران

ربات رایگان است. کاربر جدید پس از Start دکمه **وارد کردن کد ورود** را می‌بیند و با کدی که مالک از بخش **مدیریت دسترسی** ساخته است وارد می‌شود. مالک هنگام ساخت کد، یک‌بارمصرف یا چندبارمصرف بودن آن را انتخاب می‌کند. کد چندبارمصرف تا زمان غیرفعال‌شدن قابل استفاده است و پنل مدیریت تعداد ورودها و شناسه تلگرام کاربران استفاده‌کننده را نشان می‌دهد. هر کاربر یک فضای کاری مستقل می‌گیرد.

استفاده از کد ورود به‌معنای نیروی مالک یا عضو تیم او بودن نیست؛ عضویت نیرو فقط از بخش **چارت نیروها** و با افزودن صریح آیدی تلگرام ایجاد می‌شود.

## اجرا

```powershell
python main.py
```

برای ارسال پیام‌های ساعت ۲۲ و یادآورها، برنامه باید همواره روی یک کامپیوتر یا سرور روشن در حال اجرا باشد.

## قالب پیشنهادی پیام جلسه

```text
جلسه بررسی فروش
فردا ساعت 10:30 تا 11:30
حاضرین: تیم فروش
```

تاریخ شمسی صریح مانند `۱۴۰۵/۰۵/۲۴ ساعت ۱۰:۳۰` نیز پشتیبانی می‌شود. اگر زمان پایان در متن نباشد، مدت جلسه یک ساعت در نظر گرفته می‌شود.
